**ВЕРДИКТ: НЕТ. Граница regret для CTW-подобного алгоритма с жёстким бюджетом M узлов и онлайн-вытеснением относительно класса T_M на сегодняшний день НЕ опубликована.** 

Ниже — систематический разбор всех релевантных работ.

---

## 1. Context Tree Weighting — оригинал (БЕЗ ограничения памяти)

**Willems, Shtarkov, Tjalkens (1995)** — «The Context-Tree Weighting Method: Basic Properties»  
**DOI:** [10.1109/18.382012](https://doi.org/10.1109/18.382012)

- **(а) Модель памяти:** растёт с глубиной D. Число узлов ≤ 2·|алфавит|^D. На практике D = O(log T), так что память ~ O(T) в худшем случае.
- **(б) Механизм ограничения:** отсутствует. Полное дерево фиксированной глубины.
- **(в) Класс сравнения:** все древовидные источники (tree sources) с глубиной ≤ D.
- **(г) Теоретическая оценка:** **ДА**, individual-sequence bound.
- **(д) Формула:** redundancy ≤ (|S|/2) log(T/|S|) + O(1), где |S| — число листьев истинного источника.

**Willems (1998)** — «The Context-Tree Weighting Method: Extensions»  
**DOI:** [10.1109/18.661523](https://doi.org/10.1109/18.661523)

- **(а) Модель памяти:** бесконечная глубина, растёт с T.
- **(б) Механизм ограничения:** отсутствует.
- **(г) Теоретическая оценка:** **ДА** (асимптотическая оптимальность для всех tree sources).
- **(д)** individual-sequence, достигает энтропии источника.

---

## 2. Context Tree Switching (Veness и соавторы)

**Veness, Ng, Hutter, Bowling (2012)** — «Context Tree Switching»  
**DOI:** [10.1109/DCC.2012.39](https://doi.org/10.1109/DCC.2012.39) | arXiv: [1111.3182](https://arxiv.org/abs/1111.3182)

- **(а) Модель памяти:** без жёсткого бюджета; растёт с T, хотя авторы отмечают «лучшие вычислительные свойства, чем CTW».
- **(б) Механизм ограничения:** модификация рекурсивного взвешивания CTW (switching вместо weighting). НЕ является усечением/забыванием/вытеснением.
- **(в) Класс сравнения:** более широкий класс, чем CTW — все контекстные деревья (включая неполные).
- **(г) Теоретическая оценка:** **ДА** (аналитическая regret bound).
- **(д) Формула:** regret = O(|S| log T) для individual sequences, константа аналогична CTW.

---

## 3. Adaptive Context Tree Weighting (взвешивание с забыванием)

**O'Neill, Hutter, Shao, Sunehag (2012)** — «Adaptive Context Tree Weighting»  
**DOI:** [10.1109/DCC.2012.38](https://doi.org/10.1109/DCC.2012.38) | arXiv: [1201.2056](https://arxiv.org/abs/1201.2056)

- **(а) Модель памяти:** растёт с глубиной, без жёсткого лимита.
- **(б) Механизм ограничения:** экспоненциальное взвешивание недавних наблюдений (forgetting через неравные веса). НЕ усечение дерева и не бюджет узлов.
- **(в) Класс сравнения:** стандартный CTW (эмпирически).
- **(г) Теоретическая оценка:** **НЕТ** — только эмпирические результаты на нестационарных данных.

---

## 4. Finite Window CTW (скользящее окно)

**Sakaguchi, Kawabata (2000)** — «A Context Tree Weighting Algorithm with a Finite Window»  
**DOI:** [10.1002/(SICI)1520-6440(200001)83:1<21::AID-ECJC3>3.0.CO;2-X](https://doi.org/10.1002/(SICI)1520-6440(200001)83:1<21::AID-ECJC3>3.0.CO;2-X)

- **(а) Модель памяти:** ограничена размером окна W (счётчики обновляются только по последним W символам).
- **(б) Механизм ограничения:** скользящее окно / forgetting. НЕ жёсткий бюджет узлов.
- **(в) Класс сравнения:** CTW с неограниченным окном.
- **(г) Теоретическая оценка:** частично (анализ построения дерева), но граница regret для окна W ≠ граница для бюджета узлов M.

**Rashid, Kawabata (2003)** — «A Zero-Redundancy Estimator for FWCTW»  
**DOI:** [10.1109/isit.2003.1228128](https://doi.org/10.1109/isit.2003.1228128)

- Теоретический анализ zero-redundancy оценки для FWCTW, но не regret bound для бюджетного CTW.

---

## 5. D2-CTW / UCTW (Dynamic-Depth CTW) — единственная работа с жёстким бюджетом узлов

**Messias, Whiteson (2017)** — «Dynamic-Depth Context Tree Weighting» (NeurIPS)  
URL: [papers.nips.cc](https://papers.nips.cc/paper/6925-dynamic-depth-context-tree-weighting)

- **(а) Модель памяти:** **ЖЁСТКИЙ БЮДЖЕТ** — параметр M (максимальное число узлов).
- **(б) Механизм ограничения:** динамическое расширение суффиксного дерева + **прунинг (усечение)** малополезных поддеревьев + **вытеснение** узлов при достижении лимита M. Счётчики β пересчитываются при операциях с топологией дерева.
- **(в) Класс сравнения:** CTW с фиксированной глубиной (эмпирически).
- **(г) Теоретическая оценка:** **НЕТ.** Авторы приводят ТОЛЬКО эмпирические результаты. **Более того, в рецензиях NeurIPS явно отмечено: «it's not clear what happens to the regret».** Никакой regret bound относительно класса T_M (деревья с ≤ M листьев) или любого другого класса не доказан.
- **(д)** —

---

## 6. Complexity Reduction CTW (практические техники)

**Willems, Tjalkens (1997)** — «Complexity Reduction of the Context-Tree Weighting Algorithm: A Study for KPN Research»  
Технический отчёт EIDMA RS.97.01 (Eindhoven University of Technology)

- **(а) Модель памяти:** практические техники сокращения памяти (например, хеш-таблицы, отсечение по порогу счётчиков).
- **(б) Механизм ограничения:** удаление узлов с нулевыми или минимальными счётчиками, ограничение глубины, отсечение по порогу.
- **(в) Класс сравнения:** полный CTW (эмпирически).
- **(г) Теоретическая оценка:** **НЕТ** — это инженерный отчёт без regret bounds.

---

## 7. Близкая, но не CTW работа: Helmbold & Schapire (1995/1997)

**Helmbold, Schapire** — «Predicting Nearly As Well as the Best Pruning of a Decision Tree»  
**DOI:** [10.1023/a:1007396710653](https://doi.org/10.1023/a:1007396710653)

- **(а)-(д):** Решает задачу regret для прунинга *решающих деревьев* (decision trees) в модели экспертов (expert advice), а не для CTW. Это родственная задача с *теоретической* regret bound для прунинга, но **алгоритмически это не CTW**, а multiplicative weights над классом всех поддеревьев.

---

## Ответ на главный вопрос

**Опубликована ли где-либо граница regret для CTW-подобного алгоритма с жёстким бюджетом M узлов и онлайн-вытеснением относительно класса T_M (деревья с ≤ M листьев)?**

### НЕТ.

Единственная работа, реализующая именно такое поведение — **D2-CTW** (Messias & Whiteson, NeurIPS 2017) — даёт только эмпирические оценки и **не содержит теоретической границы regret**. Рецензенты NeurIPS явно отметили этот пробел. 

Остальные работы либо:
- не имеют жёсткого бюджета узлов (CTW, Context Tree Switching, Adaptive CTW),
- реализуют forgetting/окно, но не прунинг по бюджету узлов (FWCTW, ACTW),
- являются техническими отчётами без regret-анализа (Complexity Reduction),
- решают задачу в другой модели (Helmbold & Schapire — decision trees).

**Это открытая теоретическая проблема.**
