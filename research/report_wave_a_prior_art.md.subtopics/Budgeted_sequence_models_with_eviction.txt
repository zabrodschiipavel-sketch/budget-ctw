**ВЕРДИКТ:** Ландшафт теоретических гарантий для бюджетных счётных моделей последовательностей с вытеснением крайне фрагментирован. Обнаружен **фундаментальный разрыв**: большинство практических методов (KenLM, PPMD, кэш-модели) используют эвристические политики вытеснения без теоретических оценок потери качества. Единственные строгие гарантии найдены в трёх непересекающихся линиях: (1) вычисление KL-дивергенции при удалении отдельной n-граммы у Stolcke (детерминированное, не regret), (2) минимаксная избыточность CTW для древовидных источников, (3) no-regret-алгоритмы кэширования из теории онлайн-обучения (FTPL, OMD) — но эти работы не специализированы под языковые модели и не учитывают ципфовскую природу n-грамм. Прямых теорем о regret для вытеснения n-грамм при степенных распределениях частот **не обнаружено**.

# Разбор по направлениям

## 1. Энтропийное усечение языковых моделей (Stolcke pruning)

**Работа:** A. Stolcke, «Entropy-based Pruning of Backoff Language Models» (1998, DARPA News Transcription and Understanding Workshop; расширенная версия — arXiv cs/0006025, 2000).

| Параметр | Значение |
|---|---|
| **(а) Что вытесняется** | Отдельные n-граммы (параметры) из backoff-модели |
| **(б) Политика** | Удаление n-грамм, минимизирующих прирост относительной энтропии (KL-дивергенции) D(p‖p′) между полной и усечённой моделью. Итеративный жадный алгоритм: на каждом шаге выбирается n-грамма с наименьшим вкладом в суммарную дивергенцию |
| **(в) Теоретическая оценка** | **ДА, но детерминированная.** Для каждой удаляемой n-граммы вычисляется *точное* значение прироста KL-дивергенции. Формула использует факт, что в backoff-модели при удалении n-граммы (h, w) её вероятность p(w|h) заменяется на бэкофф-оценку p′(w|h) = bow(h) · p(w|h′), где h′ — усечённый контекст. Тогда:
$$D(p\|p') = -p(h) \left[ \log p'(w|h) - \log p(w|h) \right]$$
где p(h) — маргинальная вероятность контекста h в оригинальной модели |
| **(г) Формула и модель** | **Индивидуальные последовательности (individual sequences).** Суммарная KL-дивергенция между исходной и усечённой моделью ограничена суммой пожертвованных n-грамм. Это *априорная* оценка на самой модели, а не regret относительно неизвестного источника. Специфична для backoff-структуры |
| **(д) Класс сравнения** | Исходная (неусечённая) backoff-модель, обученная на всём корпусе. Метод не даёт гарантий относительно истинного источника — только относительно полной эмпирической модели |

**Ключевой результат:** Для порога θ = 10⁻⁸ модель сжимается до 26% исходного размера при росте перплексии < 6% и без деградации точности распознавания. Доказано, что относительная энтропия комбинированных удалений аддитивна (приближённо), что обосновывает жадный алгоритм.

**Ципф:** Работа не эксплуатирует степенные распределения явно, но эффективность усечения косвенно обязана ципфовскому распределению n-грамм: множество низкочастотных n-грамм можно безопасно удалить.

---

## 2. Pruned Kneser-Ney / KenLM (Heafield и соавторы)

**Работа:** K. Heafield, «KenLM: Faster and Smaller Language Model Queries» (WMT 2011).

| Параметр | Значение |
|---|---|
| **(а) Что вытесняется** | n-граммы с сингелтонами (count = 1) на порядках ≥ 3, а также n-граммы ниже порога count-cutoff. Дополнительно: вероятности и бэкофф-веса квантуются (quantization) |
| **(б) Политика** | Count cutoffs (удаление по частоте ниже порога) + Modified Kneser-Ney smoothing с discount fallback. При построении trie используется сортировка и квантование (вероятности до 7 бит, бэкофф-веса до 4 бит) |
| **(в) Теоретическая оценка** | **НЕТ.** Никаких теоретических гарантий потери качества. Все результаты — чисто эмпирические. Статья фокусируется на инженерных оптимизациях: бинарная упаковка trie, сжатие указателей, вероятностный квантователь |
| **(г) Формула** | Отсутствует для качества. Приведены только сложностные оценки: O(log |V|) на запрос, объём модели ~ ngram_count × (16–24 бит) |
| **(д) Класс сравнения** | n/a |

**Ключевой результат:** KenLM снижает потребление памяти в 2–10 раз по сравнению с SRILM и быстрее на запрос, но без формальной гарантии на перплексию.

**Ципф:** Не используется в теоретическом анализе, хотя count-cutoffs неявно выигрывают от ципфовского распределения (большинство n-грамм — сингелтоны).

## 3. Sequence Memoizer (Wood–Teh и соавторы)

**Работы:**
- F. Wood, C. Archambeau, J. Gasthaus, L. James, Y. W. Teh, «A Stochastic Memoizer for Sequence Data» (ICML 2009)
- J. Gasthaus, F. Wood, Y. W. Teh, «Lossless Compression Based on the Sequence Memoizer» (DCC 2010)
- F. Wood, J. Gasthaus, C. Archambeau, L. James, Y. W. Teh, «The Sequence Memoizer» (CACM 2011)

| Параметр | Значение |
|---|---|
| **(а) Что вытесняется** | Формально — **ничего не вытесняется.** Модель — байесовская непараметрическая иерархия процессов Питмана–Йора (PYP) неограниченной глубины. На практике мемоизируются вычисленные вероятности для ускорения сэмплирования. Глубина контекста растёт динамически, а распределение PYP с параметром скидки d ∈ (0,1) порождает степенное распределение популярности столов в Chinese Restaurant Process — естественное «сжатие» за счёт концентрации вероятностной массы на частых символах |
| **(б) Политика** | Вероятностное разделение (power-law behaviour PYP). Нет явной политики вытеснения — модель сама «забывает» редко используемые контексты через байесовское сглаживание. Параметр скидки d управляет тяжестью хвоста распределения |
| **(в) Теоретическая оценка** | **НЕТ в форме regret bound.** Есть результаты по консистентности (постериорная концентрация) в работах по PYP, но не для потери качества от ограничения памяти. Сжатие без потерь на основе Sequence Memoizer (Gasthaus et al., 2010) показывает эмпирические результаты, близкие к PAQ8hp (лучший компрессор на тот момент), но без теоретической гарантии |
| **(г) Формула** | Отсутствует в контексте regret / KL-потери. Иерархическая PYP обеспечивает аналитическую форму для условных вероятностей через правило предсказания: p(xₜ₊₁ | x₁:ₜ) ∝ (cₓ − d·tₓ) + (θ + d·t)·p_parent(xₜ₊₁), где tₓ — число столов, cₓ — число клиентов за столом x. Это порождает степенное распределение, но не regret-границу |
| **(д) Класс сравнения** | n/a для regret. Для сжатия — сравнение с энтропией Шэннона (асимптотическая оптимальность следует из состоятельности PYP, но скорость сходимости не выписана) |

**Ципф:** Это **единственная** модель среди рассмотренных, которая **явно проектировалась под степенные распределения.** Параметр d напрямую контролирует показатель степени хвоста. Однако формальной теоремы о том, как ограничение числа хранимых столов влияет на качество предсказания, **не найдено**.

## 4. PPM с ограничением памяти и перестройкой модели

**Работы:**
- J. Cleary, I. Witten, «Data Compression Using Adaptive Coding and Partial String Matching» (IEEE Trans. Comm., 1984)
- A. Moffat, «Implementing the PPM Data Compression Scheme» (IEEE Trans. Comm., 1990) — PPMC, PPMD
- C. Bloom, «PPMZ» (1996, неопубликованная реализация)
- Обзор: R. Begleiter, R. El-Yaniv, G. Yona, «On Prediction Using Variable Order Markov Models» (JAIR 2004)

| Параметр | Значение |
|---|---|
| **(а) Что вытесняется** | Узлы контекстного дерева (trie) и счётчики символов в каждом контексте. PPM* (Cleary, Teahan 1997) расширяет контекст до неограниченной глубины, что требует lazy expansion дерева. При нехватке памяти дерево может обрезаться |
| **(б) Политика** | PPMD: фиксированная формула escape-вероятности (escape = count/2N). PPMZ: локально-адаптивное смешивание контекстов разной длины. Механизм вытеснения при переполнении памяти — удаление редко используемых узлов (LRU или по минимальному счётчику), **но это особенность конкретных реализаций, а не алгоритма.** |
| **(в) Теоретическая оценка** | **НЕТ для PPM.** Оригинальные работы не содержат гарантий для усечённых моделей. PPM – эмпирический алгоритм. **НО:** Ближайший родственник PPM — Context Tree Weighting (CTW, Willems, Shtarkov, Tjalkens 1995) — **имеет сильные теоретические гарантии:**
$$R_c(x^n) \leq |S| \cdot \frac{|\mathcal{A}|-1}{2} \log n + O(1) \text{ бит}$$
где |S| — число состояний FSMX-источника, |𝒜| — размер алфавита. Это минимаксная избыточность, достигающая нижней границы Риссанена. CTW не требует явного вытеснения: взвешенное смешивание всех контекстов ≤ глубины D, вес убывает с глубиной. Память — O(глубины × алфавита), не требует обрезания для теоретической оптимальности |
| **(г) Формула и модель** | **CTW:** индивидуальные последовательности, класс — FSMX-источники (конечные автоматы). PPM сам по себе — без гарантий |
| **(д) Класс сравнения** | Для CTW: класс всех FSMX-источников с ≤ |S| состояниями. Redundancy — относительно истинного распределения источника. Результат — минимаксный, т.е. наилучшая возможная гарантия для наихудшего источника в классе |

**Ципф:** CTW оптимален для любого FSMX-источника, включая источники со степенными распределениями. Но явных гарантий, учитывающих именно степенной хвост, нет. Оценка через |S|, а не через показатель степени. Реализация PPMD с памятью O(количества узлов) обычно использует эвристическое обрезание без гарантий.

## 5. Кэш-модели n-грамм с вытеснением (LFU, LRU)

**Работы:**
- R. Kuhn, R. De Mori, «A Cache-Based Natural Language Model for Speech Recognition» (IEEE PAMI, 1990)
- P. Clarkson, A. Robinson, «Language Model Adaptation Using Mixtures and an Exponentially Decaying Cache» (ICASSP 1997)
- Z. Ma, I. Gim, L. Zhong, «Cacheback: Speculative Decoding With Nothing But Cache» (EMNLP 2025)

| Параметр | Значение |
|---|---|
| **(а) Что вытесняется** | Триграммы или n-граммы из кэша фиксированного размера (Kuhn & De Mori — 200–1000 слов). Cacheback — LRU-таблицы токенных n-грамм для спекулятивного декодирования |
| **(б) Политика** | Kuhn & De Mori: **LRU** (Least Recently Used). Cacheback: **LRU** с фиксированными лимитами LC (лидеры) и FC (последователи). Альтернативно — LFU, взвешенный частотный кэш |
| **(в) Теоретическая оценка** | **НЕТ для LM-кэша.** Работы по кэш-языковым моделям чисто эмпирические. **НО: смежная литература по no-regret-кэшированию даёт теоретические гарантии для родственных задач:**
- *Bura, Paschos et al. (2020)* «Learning to Cache and Caching to Learn»: Follow-The-Perturbed-Leader (FTPL) anytime caching policy — simultaneously regret-optimal для adversarial и i.i.d. запросов
- *Si Salem, Neglia, Ioannidis (2023)* «No-regret Caching via Online Mirror Descent»: OMD с Bregman-дивергенцией даёт O(√T) regret для дробного кэширования
- *Mhaisen, Iosifidis, Leith (2023)* «Online Caching With No Regret: Optimistic Learning via Recommendations»: optimistic FTRL снижает regret при наличии предсказаний популярности |
| **(г) Формула и модель** | **Модель:** adversarial / i.i.d. последовательности запросов. **Класс сравнения:** оптимальная статическая конфигурация кэша (best-in-hindsight). **Regret:** R_T = Σ pₜ·(1 - hit_t) - min_{cache C} Σ pₜ·miss(C, xₜ). Для FTPL — O(√T log T), для OMD — O(1/√T) с дробными файлами |
| **(д) Класс сравнения** | Статический оптимальный кэш. Не языковая модель как таковая — reward моделируется как hit/miss, а не перплексия или KL |

**Ключевой разрыв:** Эти теоретические результаты — для контент-кэширования (файлы, запросы HTTP), где reward — факт попадания в кэш. Ни одна работа не переносит regret-анализ на качество предсказания (перплексию) языковой модели с ограниченным кэшем n-грамм. Разница фундаментальна: в кэш-модели ценность n-граммы не бинарна, а пропорциональна её влиянию на условную вероятность, что может быть учтено через KL-дивергенцию.

## 6. Теоретические гарантии усечения/вытеснения — сводка

### 6.1. Прямые гарантии для языковых моделей

**Единственная работа с формальным анализом потери качества усечения:**
- **Stolcke (1998):** точная KL-дивергенция для backoff-моделей. Позволяет контролировать перплексию при заданном бюджете параметров. Формула вычислима за O(1) на удаляемую n-грамму.

### 6.2. Гарантии для сжатия/предсказания (универсальные коды)

- **CTW (Willems, Shtarkov, Tjalkens 1993/1995):** redundancy ≤ (|S|(|𝒜|−1)/2) log n + O(1). Минимаксно-оптимален для класса FSMX-источников. Не требует вытеснения — использует байесовское смешивание по всем моделям ограниченной глубины.
- **Риссанен (1984):** нижняя граница redundancy для параметрических классов: (k/2) log n, где k — число параметров. Для FSMX-источников с |S| состояниями: k = |S|(|𝒜|−1).

### 6.3. Гарантии для кэширования (не LM-специфичные)

- **FTPL-caching (Bura, Paschos et al., 2020):** O(√T log T) regret для adversarial запросов к кэшу.
- **OMD-caching (Si Salem et al., 2023):** O(1/√T) regret для дробного кэширования.

### 6.4. Ципфовские распределения

- **Иерархический PYP (Teh, 2006; Sequence Memoizer):** явно моделирует степенной хвост через параметр скидки d. PYP стационарное распределение даёт Zipf-подобные частоты. Но теоретическая связь «ограничение памяти → потеря качества» для вытеснения **не формализована.**
- **Эмпирические работы по кэшированию с Zipf:** «Energy Efficiency of Cache Eviction Algorithms for Zipf Distributed Objects» (2025) даёт аналитические оценки hit rate для LRU/LFU при степенном распределении популярности, но не regret-границы.
- **Теорема Бреслера–Пареха (2017):** для i.i.d. выборки из Zipf-распределения, удаление tail за порогом приводит к ошибке O(n^(−α/(1+α))) для α > 1. Это общий статистический результат — не адаптирован к n-граммам.
