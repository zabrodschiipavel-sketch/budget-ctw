## Оптимальное усечение контекстного дерева под жёсткий бюджет листьев

### 1. Cost-complexity pruning (Breiman et al., CART)

Пусть $T_{\max}$ — полное дерево, $T$ — его поддерево (получаемое заменой некоторых внутренних узлов листьями), $\widetilde{T}$ — множество листьев $T$, $R(T)=\sum_{t\in\widetilde{T}} r(t)$ — аддитивная стоимость (ошибка/кодовая длина). Cost-complexity критерий (Breiman, Friedman, Olshen, Stone, 1984):

$$R_\alpha(T) = R(T) + \alpha|\widetilde{T}|.$$

Для каждого $\alpha \ge 0$ существует единственное минимальное поддерево $T(\alpha) \subseteq T_{\max}$, минимизирующее $R_\alpha$. При $\alpha=0$ это $T_{\max}$, при $\alpha\to\infty$ — корень. Алгоритм «weakest-link pruning» вычисляет для каждого внутреннего узла $t$ критическое значение

$$g(t) = \frac{r(t) - R(T_t)}{|\widetilde{T}_t| - 1},$$

где $T_t$ — поддерево с корнем $t$. На каждом шаге отсекается узел с минимальным $g(t)$; процесс порождает вложенную последовательность $T_0 \supset T_1 \supset \dots \supset T_K$. Сложность: один bottom-up проход $O(N)$, где $N$ — число узлов полного дерева.

**Доказанная гарантия (Breiman et al., Theorem 3.5):** Каждое $T_k$ минимизирует $R(T)$ среди *всех* поддеревьев с тем же числом листьев, что и $T_k$. Для произвольного бюджета $M$ гарантии *не* даётся: если $|\widetilde{T}_k| > M > |\widetilde{T}_{k+1}|$, то оптимум для $M$ может не принадлежать последовательности $\{T_k\}$.

### 2. Chou–Lookabaugh–Gray и обобщённый BFOS

Chou, Lookabaugh, Gray (1989) перенесли cost-complexity pruning на tree-structured vector quantization, минимизируя distortion $D$ при штрафе за rate $R$: $D+\lambda R$. Алгоритм, названный ими G-BFOS (generalized BFOS), делает то же самое: один bottom-up проход за $O(N)$, обходит все $\lambda$ и порождает точки operational distortion-rate кривой.

**Ключевое ограничение — доказано Chou (1991):** «A pruning algorithm of P.A. Chou et al. (1989) for designing optimal tree structures identifies *only those codebooks which lie on the convex hull* of the original codebook's operational distortion rate function.» Точки, лежащие *внутри* выпуклой оболочки множества достижимых пар $(R,D)$, не достижимы ни при каком $\lambda$.

Таким образом, лагранжева развёртка (пробег $\lambda$) **не** гарантирует точный оптимум для заданного бюджетного ограничения $M$. Точный оптимум достигается тогда и только тогда, когда точка $(M, f(M))$ лежит на нижней выпуклой оболочке функции $f(m) = \min_{|\widetilde{T}|=m} R(T)$. Если $f$ невыпукла в $m=M$, имеет место ненулевой duality gap: лагранжев подход выдаёт значение, соответствующее выпуклой комбинации двух деревьев с разным числом листьев — физически нереализуемой.

### 3. Сложность на полном бинарном дереве глубины $D$

Над бинарным алфавитом полное контекстное дерево глубины $D$ содержит $N = 2^{D+1}-1$ узлов, из них $2^D$ листьев.

**Cost-complexity / G-BFOS:** $O(N) = O(2^D)$ по времени, $O(N)$ по памяти — один bottom-up проход. Мгновенно порождает всю последовательность $\{T_k\}$ для всех $\alpha$ (или $\lambda$).

**Точный DP по бюджету листьев:** Определим $dp[v][b]$ = минимальная стоимость поддерева с корнем $v$, содержащего ровно $b$ листьев. База: для листа $dp[\,\text{leaf}\,][1] = r(\text{leaf})$, остальные $b$ — $\infty$. Переход для внутреннего узла: $dp[v][1] = r(v)$; для $b>1$:

$$dp[v][b] = \min_{i=1}^{b-1} \big( dp[\text{left}][i] + dp[\text{right}][b-i] \big).$$

Время: $O(N \cdot M^2)$, память: $O(N \cdot M)$, где $M$ — бюджет листьев. Для полного дерева $M \le 2^D$. В худшем случае ($M \approx 2^D$): время $O(2^{3D})$ — экспонента от $D$, память $O(2^{2D})$. Практически нереализуемо для $D$ свыше 10–12.

Возможна оптимизация свёрткой через FFT (если стоимости образуют полукольцо), но гарантий полиномиальной сложности от $D$ нет — задача NP-трудна в общей постановке budget-constrained tree pruning (сводится к Knapsack на деревьях).

### 4. Энтропийное усечение (Stolcke pruning)

Stolcke (1998, arXiv: cs/0006025) предложил эвристику для усечения backoff n-gram языковых моделей: на каждом шаге удаляется n-грам, дающий наименьший прирост относительной энтропии (KL-дивергенции) между исходной и усечённой моделью. Критерий для отдельного n-грама $w_1^n$:

$$\Delta D = -p(w_1^{n-1}) \cdot \Big[ p(w_n|w_1^{n-1}) \log \frac{p(w_n|w_1^{n-1})}{\alpha' p(w_n|w_2^{n-1})} + p(\cdot|w_1^{n-1}) \log \frac{p(\cdot|w_1^{n-1})}{\alpha' p(\cdot|w_2^{n-1})} \Big].$$

Хотя Stolcke использует относительную энтропию как формальный критерий, сама процедура — **жадная эвристика без доказанных гарантий оптимальности**. Это инженерная практика: удаляем n-граммы с наименьшим $\Delta D$, пока не достигнут желаемый размер модели. Никакого отношения к точному оптимуму под бюджет листьев не имеет. Работает хорошо на практике для языковых моделей (perplexity-деградация порядка единиц процентов при сокращении модели на 50–70%), но теоретической связи с бюджетным оптимумом нет.

### 5. Итоговое сопоставление

Лагранжев подход (cost-complexity, G-BFOS) даёт **точный оптимум** для задачи $\min_T (R(T) + \lambda|\widetilde{T}|)$ — то есть для *всех* точек на нижней выпуклой оболочке достижимых пар $(|\widetilde{T}|, R)$. Для задачи с жёстким бюджетом $\min_{|\widetilde{T}|\le M} R(T)$ он даёт точный ответ лишь когда $(M, f(M))$ лежит на выпуклой оболочке. Если нет — только верхнюю границу (результат выпуклой релаксации). Доказательство: Chou (1991) явно фиксирует «identifies only convex hull points».

Точный DP по бюджету существует, но стоит $O(N M^2)$ времени — для полного дерева над бинарным алфавитом это $\Theta(2^{3D})$, что делает его неприменимым на практике для $D$ больше ~10.

Для budget-CTW с жёстким бюджетом $M$ узлов практическая стратегия: использовать лагранжев подход для порождения последовательности кандидатов $\{T_k\}$ за $O(2^D)$, и выбрать наименьшее $T_k$ с $|\widetilde{T}_k| \le M$ (что гарантирует оптимальность на выпуклой оболочке, но может упустить interior-point оптимум на величину до $O(\Delta R)$ где $\Delta R$ — максимальная невыпуклость $f$).
